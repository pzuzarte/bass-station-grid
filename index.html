        Bass Station Grid help

        A pattern grid for the Novation Bass Station II, with a sound editor on the Editor tab. It runs in your browser and sends MIDI to the Bass Station. Your patterns stay on this computer. It needs a current Chrome or Edge on a computer. It's unofficial and not affiliated with Novation.

        Visits to this page are counted anonymously with GoatCounter, which uses no cookies. It never receives your patterns.

        Set up

        1. Connect the Bass Station to your computer with USB, and turn it on.
        2. Allow MIDI access when asked. The MIDI badge turns green when the Bass Station is found. If it says MIDI blocked, click the icon to the left of the address, set MIDI devices to Allow, then click Allow MIDI.
        3. Click a note name in the grid. You should hear it on the Bass Station.
        4. Check that Channel at the bottom matches the Bass Station's MIDI channel.

        Editor tab

        • This is the Bass Station II Web Editor by François Georgy, an unchanged copy of the version on his site. It's free software under the GPL-3.0, and its source is on GitHub. It has every setting, and its Sync reads the patch the Bass Station is playing. Its own help explains the rest.
        • It loads the first time you open the tab. Choose the Bass Station as its input and output in its Settings.
        • The editor and the grid both talk to the Bass Station, so you can edit the sound while a pattern plays.

        Sounds tab

        • On the Bass Station lists its 128 patches with their factory names, from Novation's patch sheet. Click one to choose it on the synth, and the Editor tab follows. The names are only the factory ones, as the Bass Station doesn't store names, so any you've overwritten still show the factory name.
        • Back up all 128 steps the Bass Station through every patch, reads each one, and goes back to the patch you were on. It takes about half a minute. Unsaved changes to the current sound are lost, so save first. The backup is saved as one .syx file in the library folder's Backups folder, which other Bass Station tools can read too.
        • Save current sound adds the sound the Bass Station is playing to the library, under a name you choose.
        • The Sound library is a folder on this computer that you choose with Choose library folder. Each sound is saved there as its own .syx file, named after the sound, so it's kept even if the browser's data is cleared, and your usual backups include it. Where each sound came from is kept in library-info.json in the same folder. After Chrome restarts, click Allow library folder to use it again.
        • .syx files you put in the folder yourself show up too, if each holds one Bass Station patch.
        • Load sends a sound to the Bass Station through the editor, which sets every control. To keep it in a patch slot, save it on the Bass Station. Rename and Delete change its file. Import .syx adds every patch in a file, and Export all downloads the whole library as one file. Add to library on a backup adds each of its patches.
        • Reading patches needs MIDI with SysEx, which Chrome asks about the first time.

        Working in a key

        • Choose a Key and Scale. The grid only shows notes in that key, so anything you draw fits. Move notes with key moves your patterns into a new key when you change it. All notes shows every note.
        • Idea and Generate write a bassline, melody or arpeggio in the key, and Undo brings back the old one.
        • The Bass Station plays one note at a time, so each step holds one note. Clicking a different note in a step replaces the one there.
        • Shift moves the whole pattern a step earlier or later, Scale moves every note a step through the scale, and Oct moves them an octave.
        • Click or drag along the step numbers to choose steps, then Copy and Paste. Velocity and Set change the chosen steps, or the whole pattern.

        Mouse and keyboard

        Click a stepAdd or remove it, replacing any other note in that step. New steps use the Length setting.
        Drag from an empty stepDraw one note as long as you drag. Hold Alt for single ticks.
        Drag a noteChange where it ends, from its first step or its end marker. It moves in eighths of a step, or hold Alt for single ticks.
        Cmd-drag across stepsFill separate steps, or remove them when starting from a filled step.
        Right-click a stepEdit velocity, length, timing, probability and sub-steps.
        Shift-click a stepCycle velocity: full, 70%, 40%.
        SpacePlay and stop, unless you're typing in a text box or using the Editor tab.
        TTurn triplets on or off.
        Cmd or Ctrl + ZUndo.
        ? and EscOpen this help, and close it or the step editor.

        Chains, knob movements and files

        • Sub-step, in the step editor, plays a step in quick repeats, where o plays and - is silent.
        • Rec records notes into the pattern from the input and channel chosen beside it: the Bass Station's own keys, another keyboard, or any input on any channel. While playing, notes land on the nearest step and last exactly as long as you hold them, not rounded to whole steps, and each time round the loop adds to what's there. They then play back on the Bass Station like any other steps. While stopped, each key adds a note and moves on a step, starting from the chosen step. Undo takes back the whole take. The Bass Station plays one note at a time, so a recorded note replaces any other note on its step.
        • Click plays a metronome click on each beat while the pattern plays, louder on the first beat of each bar. It comes from this computer's speakers, not the instrument, and stays on or off for next time.
        • While recording, notes from another keyboard are passed on to the Bass Station so you hear them. If MIDI Hub is also routing that keyboard to the Bass Station, you'll hear each note twice, so choose one.
        • Chain takes pattern numbers such as 1 1 2 3. Tick On and Play goes through them in order, looping.
        • Knobs opens a lane under the grid to draw how a Bass Station knob, such as filter frequency, moves through the pattern. Alt-drag erases, and Copy all to copies the movements to another pattern. Each pass starts from where the knob was last turned on the Bass Station.
        • Patterns 1-16 are stored in this browser. Back up saves them to one file, and Restore loads it back. Export MIDI and Import MIDI work with one pattern at a time. Importing a file with chords keeps the highest note of each.
        • Sync plays this page together with S-1 Grid, MPC Grid and Protein Grid when they're open in the same browser. Play, stop and tempo are shared.
        • Send clock sends MIDI clock with playback, which the Bass Station's arpeggiator and sequencer follow.

        If you hear nothing

        • Check that the MIDI badge is green, and reload the page if the Bass Station was off when it opened.
        • Check the channel, and the Bass Station's volume and filter frequency.
        • Use Panic if a note gets stuck.
